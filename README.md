# מה מבשלים היום

ספר המתכונים המשפחתי.

## איך מתחילים

1. לפתוח טרמינל בתיקייה הזו
2. להריץ `claude`
3. להדביק את הפרומפט שב-`KICKOFF.md`

## איך מוסיפים מתכון

לפתוח `claude` בתיקייה ולכתוב:

> תוסיף מתכון חדש. הנה הטקסט / הלינק: ...

הוא יוצר קובץ `.md` חדש ב-`src/content/recipes/` לפי הסכמה ב-`SPEC.md`. אחר כך `git push` ו-Vercel מעלה גרסה חדשה תוך דקה.

## איפה מה

- `recipes/` — 19 המתכונים (יעברו ל-`src/content/recipes/` בשלב הראשון של הבנייה)
- `CLAUDE.md` — הוראות קבועות לקלוד קוד
- `SPEC.md` — האפיון המלא: דפים, מצב בישול, הדפסה, עיצוב, סדר בנייה
- `KICKOFF.md` — הפרומפט הראשון להדבקה
